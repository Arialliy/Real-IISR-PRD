# 关闭全局条件码本以后，S2 的退化是否仍然存在

**S2 的整图亮度漂移在关闭全局条件码本（CAC）后仍然存在。** 下表使用本地 NUAA-SIRST 清单中全部 213 张训练图的第一组固定噪声。每行只改变最终解码使用的码本；模型、离散编码（token）、图像解码器、精度和评价掩码固定。预测 token 来自原自回归网络，输入 token 和参考 token 分别由原 VQ 编码器从带噪图和加噪前参考图提取。参考编码仅用于诊断。

| 端点 | token 来源 | 整图 MAE：基础码本 / 全局 CAC | 背景均值偏差：基础码本 / 全局 CAC | 目标对比度绝对误差：基础码本 / 全局 CAC |
| --- | --- | ---: | ---: | ---: |
| S1 | 自由预测 | 3.556 / 3.556 | −0.439 / −0.439 | 18.412 / 18.414 |
| S1 | 带噪图编码 | 5.731 / 5.731 | +0.015 / +0.016 | 16.486 / 16.483 |
| S1 | 参考图编码 | 3.040 / 3.040 | +0.008 / +0.008 | 18.675 / 18.676 |
| S2 | 自由预测 | 27.810 / 27.810 | +27.609 / +27.609 | 22.528 / 22.525 |
| S2 | 带噪图编码 | 5.731 / 5.731 | +0.015 / +0.016 | 16.486 / 16.482 |
| S2 | 参考图编码 | 3.040 / 3.040 | +0.008 / +0.008 | 18.675 / 18.676 |

单位均为 8 位灰度级（DN）。加噪前参考图直接编码后，仅用基础码本解码，目标对比度仍平均低估 17.858 DN。S2 的预测 token 保持固定时，关闭或开启全局 CAC 得到的两幅图平均只相差 0.0086 DN；换成参考图 token 后，原先约 +27.61 DN 的背景偏移降到约 +0.008 DN。这将新增的整图漂移定位到预测 token 路径。参考编码仍损失局部对比，冻结编码器、量化和图像解码器各自的贡献还需分别测量。[S1 逐图及逐标注结果](s1_0_six_routes.json) · [S2 逐图及逐标注结果](s2_0_six_routes.json)

另外两种输入得到相同判断。S2 自由预测在 clean 上的背景偏移用两种解码均为 +27.479 DN，在第二组噪声上分别为 +27.643 与 +27.644 DN。两端、三种输入与三种 token 来源的 18 个同 token 对照中，切换最终码本造成的原生图像平均绝对差范围为 0.0071–0.0117 DN。六个条件下共 1,278 张预测图与已归档的终点输出逐像素相同；每个条件都使用同一份训练清单。[S2 零额外噪声](s2_clean_six_routes.json) · [S2 第二组噪声](s2_1_six_routes.json)

## 原生标注里有多少几像素弱点

面积取原图标注像素数，强度分层取原图目标核心均值与其两像素背景环中位数之差的绝对值。每个标注计一次。图像从未额外加噪，以下逐目标统计与整图等权结果分开报告。

| 原生面积 | <10 DN | 10 至 <30 DN | ≥30 DN | 合计 |
| --- | ---: | ---: | ---: | ---: |
| 1–4 像素 | 0 | 4 | 2 | 6 |
| 5–16 像素 | 0 | 31 | 62 | 93 |
| ≥17 像素 | 0 | 33 | 138 | 171 |

面积 1–4 像素且参考对比度为 10 至 <30 DN 的 4 个标注，原始平均对比度为 16.188 DN。用自由预测 token 和全局 CAC 重建后，S1 为 9.028 DN，S2 为 2.431 DN。同组参考编码经基础码本重建也只剩 7.654 DN。另 2 个 1–4 像素标注的原始平均对比度为 44.250 DN，S1、S2 分别为 11.141 和 7.888 DN。对比度 <10 DN 的原生标注在所有面积组均为零；该强度范围缺少原生样本。[逐标注对比及分层表](clean_native_point_strata.csv)

### 半高斑表观宽度及可测覆盖

每个标注沿用参考图的亮／暗极性，并在原生核心中寻找该极性最强的像素。局部基准为上述背景环中位数。峰高必须大于 1 DN 与背景环三倍稳健噪声估计中的较大值；稳健噪声取环内绝对中位差的 1.4826 倍。在标注外接框向四边各延伸 4 像素的窗口内，求包含该峰、响应至少达峰高一半的八连通区域。若它触及窗口边缘、与另一标注合并，或同一连通区域内在原核心外出现更强峰，宽度记为缺测。对有效半高区域面积 (A)，表观宽度为等面积圆直径 (2\sqrt{A/\pi})，单位为原生像素。它由离散图像估计，没有潜在光学点扩散函数的真值。

| 原图标注 | 参考可测 | S1 可配对 | S2 可配对 | S1 / S2 配对平均绝对宽差 |
| --- | ---: | ---: | ---: | ---: |
| 全部 270 个 | 267 | 233 | 202 | 0.618 / 0.798 px |
| 1–4 像素，10 至 <30 DN，共 4 个 | 4 | 3 | 1 | 0.371 / 0.000 px |
| 1–4 像素，≥30 DN，共 2 个 | 2 | 0 | 0 | 缺测 / 缺测 |
| 5–16 像素，10 至 <30 DN，共 31 个 | 31 | 20 | 15 | 0.510 / 0.740 px |

表中模型均为自由预测 token 加全局 CAC。1–4 像素中较低对比的 4 个点，S2 只剩 1 对可测，其半高直径恰好与参考相同，另 3 个的峰均低于分辨阈值。所有宽度误差只在参考与对应输出都可测时计算；覆盖数须与误差同时解读。分层 CSV 提供全部六条解码路径的宽度误差、缺测原因与标注总数，逐点 JSON 保存每个实测直径和半高像素面积。[S1 逐点数据](s1_clean_native_points.json) · [S2 逐点数据](s2_clean_native_points.json) · [宽度计算与分层代码](../../../measure_e_only_native_width.py)

## 实验口径和复算

使用相同的 S1 和 S2 终点，分别评估零额外噪声、固定噪声 0 和 1。逐张读取原训练清单，512×512 工作网格只为网络补边，计分只用完整原生分辨率。原条件端从实际输入图提取一个全局条件向量，同一幅图的三条 CAC 路径共用它。E-only 只把最后的查表改为基础码本，在生成下一尺度 token 时仍使用原反馈。VQ 编码保持 FP32，确定性缓存 argmax 和两种最终解码均用 CUDA FP16，TF32 关闭。直接评分采用未舍入的浮点灰度。每张图先在图内平均目标对比度误差，再对图等权。[原生指标](../../../evaluate_protocol_v2.py) · [数据采集](../../../evaluate_e_only.py) · [解码评分](../../../score_e_only.py)

每个端点及噪声条件各有一份 `*_tokens.npz`，按训练清单顺序保存三种完整的十尺度索引、每幅图的全局条件、ID、输入 SHA-256 和尺度偏移。相应的 `*_tokens.json` 登记端点、分词器、解码器及数组文件的 SHA-256。`*_six_routes.json` 保存六条路径和直接输入对照的逐图指标、逐目标指标及原尺寸浮点图像哈希。恢复出的预测 CAC 栅格与原端点浮点归档逐像素核对；第一组噪声的三条 CAC 路径另与已有探针逐图复核。在 clean 条件下对同一图分别再编码，输入与参考的索引相同，两种解码的输出也相同。[完整汇总](summary.json) · [跨条件核验](../../../summarize_e_only.py)

从项目根目录复算整套诊断。采集、解码、宽度复算使用物理 GPU 2，两个汇总步骤仅使用 CPU。已有六格 JSON 和 token 文件时，只需最后三条命令即可重做原生宽度及其交叉分层。

```bash
cd results/denoise_v2/token_sources
bash run.sh capture
bash run.sh score
bash run.sh summarize
bash run.sh width s1
bash run.sh width s2
bash run.sh width summarize
```
