# 原尺寸垂直细节对人工点斑的影响

## 测量与复算

每张图使用过去已登记的一个人工点斑，1、2、4、6、8、12 DN 六个峰值档的原图数依次为 33、43、41、33、29、34。每个条件下，同一份噪声用于有点与无点两支。点斑在噪声分支上限幅，仅 fresh 的一个点斑有 2 个像素因此截幅，所有 852 个有点输入的实测对比度增量均为正。不同噪声是同一批原图的重复测量。六档按不同原图分配，不能把档间差异全部归因于幅度。[各档结果](by_dose.csv) · [带哈希的输入输出档案](../capture/README.md)

对单幅图使用核心均值减背景环中位数定义对比度。逐图先求有点和无点输出的对比度差，再除以该图无额外噪声时真实注入的对比度增量。记录同时提供相对该噪声条件实测输入增量的比值。宽度由差分图中与峰值连通的半高斑面积换算为等面积直径，沿用上一轮的八连通、显著性、边界及单像素规则。宽度误差仅在参考和输出都可测时计算，所有缺测单列原因。各方法的可测子集可有差异。宽度覆盖的改善与局部对比度的恢复分别报告。[逐图记录](per_pair.csv) · [完整统计](summary.json) · [上一轮宽度定义](../../spot_transfer/README.md)

在项目根目录执行 `bash results/denoise_v2/native_detail/spots/run.sh` 即可用 CPU 从原尺寸采集档案重新计分。脚本检查全部 852 个档案哈希、相同注入模板和清单顺序，并将无额外噪声下 213 条输入与 213 条 S1 结果逐项同历史档案比较。配对区间以每种条件下 213 张原图为单位，5,000 次重采样，并固定随机种子 20261121。[计分入口](../../../../evaluate_native_detail_spots.py) · [复核结果](verification.json)
