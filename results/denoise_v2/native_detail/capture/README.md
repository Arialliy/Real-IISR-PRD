# S1 的原尺寸配对输出

按原训练清单顺序取 213 张 NUAA 原图。复用上一轮为每张图预先确定的点斑强度、中心、模板及背景环。每种输入条件固定点斑，两个分支共享同一幅背景。基础图像为原图时记为 `clean`，另外三组的基础图像分别对应训练图原有的 `draw0`、`draw1` 和新增的 `fresh` 噪声。后者使用随机抽样编号 20261121。各组均用数据种子 0 和 epoch 0。[点斑登记](../../spot_transfer/protocol.json) · [噪声登记](../../../../configs/denoise_v2/noise_levels.json)

在归一化灰度上，先取既有无点输入，再加固定点斑并限幅到 [0,1]。每行记录该次注入发生限幅的像素数，以及这一对图在指定核心区与背景环上的实际对比度增量。S1 使用同一份本地训练权重，FP16 单图贪心推理，关闭 TF32，输出在保存前取三通道浮点均值。直接在原像素网格计量。

每组报告列出训练样本 ID、输入和 S1 输出的 SHA-256、强度、中心及核心区面积。每个 `.npz` 的 `x_minus`、`x_plus`、`s1_minus`、`s1_plus` 都是未取整的原尺寸二维 float32 图像。`core` 和 `ring` 是同网格的布尔评价区域。模型推理只接收一幅灰度输入图。核心区和背景环用于离线评价。[无额外噪声](clean.json) · [第一份噪声](draw0.json) · [第二份噪声](draw1.json) · [新增噪声](fresh.json)

前三组无点输出读取上一轮存档，每一幅都和原索引的文件哈希核对。新增噪声组的无点输出重新前向，和该组历史逐图预测的像素哈希核对。四组有点输出均重新前向。对于无额外噪声的 213 对，另核对上一轮存下的有点／无点图块及整图差异统计。第一份噪声逐图核对这次的有点输入与原数据生成器放入相同点斑时的输出。其他噪声条件沿用 draw0 点斑，固定其原始位置。[前向与校验实现](../../../../capture_native_detail_pairs.py)

852 个配对文件均通过 SHA-256 复核，每组的 213 张图均有正的实际对比度增量。四组共享的点斑、中心、核心与背景环逐图相同。新噪声中有 1 对图的 2 个注入像素触及上限并发生截幅，其他三组均无新增截幅。draw0 的有点输入与旧生成器的有点输入在全部 213 张图上逐像素相同。

在项目根目录执行下列命令可重建四份存档。不同条件可在不同 GPU 并行，单次只运行一个相同条件。

```bash
for condition in clean draw0 draw1 fresh; do
    SIRST_DETAIL_GPU=0 bash results/denoise_v2/native_detail/capture/run.sh "$condition"
done
```
