## 两种损失分别产生了什么变化

第一个四图批次，预测头 bias 的未裁剪梯度范数为 CE 0.3902、加权图像项 0.0001055，夹角余弦 −0.0375。最后一个 Transformer 块的注意力输出 bias 对应值为 0.4259、0.0001841 和 −0.0058。原全局 CAC 的 U、V、gate 和条件分支由图像损失获得梯度。仅 CE 一臂实际建立 381 份优化器状态，完整与仅图像两臂各有 388 份。两条分项各自执行 AdamW 后，原图与带噪图的整图 MAE 都上升，单看预测头梯度大小无法解释全部漂移。[首组分项向量及梯度方向](summary.json)

完整损失首组全局 CE 为 0.80608。10 个尺度中，最细尺度对这一数值贡献 0.58648，最粗尺度贡献约 0.0000073。最粗尺度 logits 接受来自后续可微前缀的梯度，该尺度实际总梯度范数在四张训练图上的均值为 0.02685。直接 CE 的贡献大小和该尺度收到的总梯度是两项不同的测量。[逐图、逐尺度训练日志](T-ALL/updates.jsonl)

## 历史轨迹的可复核范围

第 50 步和第 54 步的数据直接读取原权重。在这两处，8 张带噪图的首尺度参考均为 3788，预测均为 2772。旧运行的第 1、4、16 步权重已被同名恢复文件滚动覆盖。重新按原协议训练时，第一个批次的三项前向损失与原日志完全相同，裁剪前梯度范数则为 226.621，旧记录为 226.566；第二步起前向损失也出现差异。因而表内复演点能说明此训练过程怎样发生早期漂移，旧运行里首尺度具体在哪一次更新翻转仍然未知。[原始日志](../../s2_common/updates.jsonl) · [首组梯度对照](T-ALL/first_gradient_replay.json)

在原训练所用的物理 GPU 3 上，直接调用原始 `train_s2_common.image_loss`，保持权重固定，对同一四图批次重复两次仅反向传播，未执行优化器更新。两次裁剪前梯度范数分别为 226.528 和 226.713，两次的三项前向损失均与旧日志完全一致。这说明原始反传在相同数据与权重上也有数值波动；该核查只覆盖首个批次，后续分叉的大小仍由复演和历史记录的实测对照给出。[只反传复核](pure_first_gradient/repeatability.json)
