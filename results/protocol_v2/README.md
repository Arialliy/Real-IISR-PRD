# SIRST 训练图同尺寸统一评价

同一张图在每种条件下使用相同输入、参考、有效区域和目标掩膜。五种处理均覆盖本地训练清单的 213 张原图。发布权重、S1 和 S2 使用确定性 greedy、FP16、关闭两种 TF32、网络返回的浮点灰度值。图像全分辨率评价，原图仅增加居中填充，计分前去除。输入即参考的一组测量模型对原图的改写。两次固定噪声实现使用按图抽取的条纹和像素噪声幅度。此实验没有物理无噪参考，也未使用 dev 或 test。[协议与校验值](protocol_v2.json) · [结果汇总](summary.json)

## 数据与复核

- [逐图表](per_image.csv) 共 3,195 行，记录输入、参考、固定背景、输出浮点缓存的路径或哈希、实际噪声幅度及新旧指标。
- [逐目标 CSV](per_target.csv) 与 [JSONL](per_target.jsonl) 共 4,050 行。同一标注原生八连通域跨方法与腐蚀均保留，可查核心和环面积、坐标、边界、历史／新对比度与增益。
- [干预分解](interventions.csv) 共 2,130 组。每组 NPZ 存储未舍入的 float64 DN 误差场：`e0_dn=255*(F(clean)−reference)`、`d_n_dn=255*(F(noisy)−F(clean))`。两者像素级求和就是 `e_n=255*(F(noisy)−reference)`。CSV 分别报告三个场的平均误差、MAE 和 RMSE，并给出二阶交叉量。相同方法的背景及输出几何一致。draw0 中新增噪声引起的输出变动 MAE 对列校正、发布权重、S1、S2 分别为 2.875、16.667、1.368、4.361 DN。
- [验收](verification.json) 重读并核对所有原图、浮点输出和干预场。合成输入检查形状广播、非有限值、PSNR 方向、符号偏差和零强度列校正；历史逐图分数与默认列校正输出像素一致。独立重复推理见[发布权重首图](../protocol_v2_levels/published_repeat.json)、[S1 全 213 图](../sirst_endpoints/s1_draw0_token_sources.json)、[S2 全 213 图](../sirst_endpoints/s2_draw0_token_sources.json)。发布权重的重复性检查仅覆盖首图。

从本目录运行 `bash run.sh --verify-only --workers 6` 可只读重验；使用 `bash run.sh --output-dir /project/results/protocol_v2_rerun --workers 6` 可在新目录重新计算。已验证的网络输出可由 `results/sirst_endpoints/run.sh --endpoint published|s1|s2 --draw clean|0|1` 分别生成。默认统一入口选择 train、五种方法及 clean/draw0/draw1。[统一计分代码](../../evaluate_protocol_v2.py)
