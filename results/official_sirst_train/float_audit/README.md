# 原版 Real-IISR 在 SIRST 训练原图上的迁移审计

以已发布的 `Real-IISR.pth` 和作者原样的 `test.py` 推理，输入为本地 NUAA-SIRST 训练清单中全部 213 张原图，固定顺序，batch 4，seed 0。此次仅观测前向与官方 PNG 保存过程。论文使用的 FLIR-IISR 4× 实验另行记录。原图、成员、权重与入口脚本的校验值分别见[输入清单](../input_manifest.json)和[汇总](summary.json)。

| 校验或差异 | 结果 |
| --- | ---: |
| 实际模型输入与重新读取原图并执行官方预处理逐元素相等 | 213 / 213 |
| 读取保存的模型浮点返回值，独立执行官方舍入与 AdaIN，所得像素与本轮官方 PNG 相等 | 213 / 213 |
| 本轮 PNG 与此前归档 PNG 的 RGB 像素完全相等 | 0 / 213 |
| 本轮与此前归档的逐图 RGB 平均绝对差，再对图像取均值 | 1.5254 DN |
| 两轮间观察到的最大单通道绝对差 | 235 DN |
| 模型浮点返回值至 8 位舍入的 RGB 平均绝对差 | 0.2500 DN |
| 模型浮点返回值至本轮最终 PNG 的灰度平均绝对差 | 9.4424 DN |

归档 PNG 的 SHA-256 全部与原运行记录一致。本轮在 GPU 1 执行，沿用原容器、输入和参数。两轮完整输出存在像素差异，具体来源未查明。涉及量化、AdaIN 与浮点输出的配对统计均使用本轮张量和同轮最终图像。[逐图结果](per_image.csv)

## 坐标与灰度

原图见[本地 NUAA-SIRST](../../../datasets/NUAA-SIRST)，逐图路径见表。作者加载器将每幅原图直接缩放到 512×512。对于宽高为 W×H 的原图，零起点像素中心 (x,y) 对应的连续模型坐标为 ((x+0.5)×512/W−0.5, (y+0.5)×512/H−0.5)。在原图掩膜上提取八连通目标，取距离该连通域质心最近的域内像素为锚点，再在最近邻投影的同一目标内选取距离映射位置最近的像素。窗口右、下界为排他端点，剖面穿过相同投影锚点。

灰度为 RGB 三通道算术均值，以 0 至 255 DN 表示。所有整图、目标窗口和剖面使用同一灰度尺度。有符号差分图统一显示 −32 至 +32 DN，零差为中灰，显示截断不影响数值统计。局部对比度取目标平均灰度减去周围背景中位数。背景由原生掩膜向各方向扩张 2 像素得到，排除全部已标注目标，再与目标一起最近邻投影到模型网格。这 270 个连通域均有可用背景。
